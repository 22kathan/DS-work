# Statistics Module — Data Science (`DS-work`)

This folder contains the complete 12-session **Statistics & Linear Algebra for Data Science** curriculum. Every session is formatted strictly as a Jupyter Notebook (`.ipynb`) with all mathematical formulas, code executions, and visualization outputs embedded directly.

---

| Session | Module Title | Key Topics Covered | Notebook Link | Status |
| :---: | :--- | :--- | :--- | :---: |
| **01** | **Introduction to Statistics in Data Science** | Numerical vs. Categorical data classification, Nominal data, Bayesian rating systems, Mean, Mode, Variance definitions | [Session 01 Notebook](./Session-01-Introduction-to-Statistics/session_1_statistics.ipynb) | ✅ Completed |
| **02** | **Mean, Median & Mode** | Spotify playlist plays mean, Zomato median delivery time, Flipkart mode rating function, YouTube outlier sensitivity, Swiggy dataset analysis | [Session 02 Notebook](./Session-02-Mean-Median-Mode/session_2_mean_median_mode.ipynb) | ✅ Completed |
| **03** | **Variance & Standard Deviation** | Fitness step counts manual variance derivation, `calculate_standard_deviation` function, Zomato spending consistency, Startup salary dispersion | [Session 03 Notebook](./Session-03-Variance-and-Standard-Deviation/session_3_variance_standard_deviation.ipynb) | ✅ Completed |
| **04** | **Skewness (Basic)** | Swiggy order count right-skew classification & plot, Instagram follower mean vs. median analysis, YouTube views right-skew case study, Flipkart ratings left-skew plot | [Session 04 Notebook](./Session-04-Skewness-Basic/session_4_skewness_basic.ipynb) | ✅ Completed |
| **05** | **Sampling** | Population vs. Sample definitions (Zomato, Instagram, Flipkart), `random_sampling_sim.py`, Swiggy delivery times sampling justification, Spotify selection bias, BookMyShow sampling strategies | [Session 05 Notebook](./Session-05-Sampling/session_5_sampling.ipynb) | ✅ Completed |
| **06** | **Hypothesis Testing (Basic)** | Null & alternative hypotheses for screen time, two-sample t-test ($t = 2.3238, p = 0.0237$) on Zomato AOV, Paytm 1-Tap Pay A/B test framework, Flipkart Wishlist button p-value interpretation | [Session 06 Notebook](./Session-06-Hypothesis-Testing-Basic/session_6_hypothesis_testing_basic.ipynb) | ✅ Completed |
| **07** | **Correlation** | Instagram hours vs. posts scatter plot & positive correlation, Zomato vs. Swiggy order count correlation ($r = +0.9984$), daily screen time vs. study hours trade-off, Spotify hours vs. test marks strong negative correlation ($r = -0.9996$) | [Session 07 Notebook](./Session-07-Correlation/session_7_correlation.ipynb) | ✅ Completed |
| **08** | **Probability Basics** | Probability function `calculate_probability`, 100-roll dice simulation (experimental vs. theoretical), Spotify genre picking probability, Zomato Food & Dessert intersection probability, Flipkart conditional probability ($P(\text{Headphones} \mid \text{Phone})$) recommendation logic | [Session 08 Notebook](./Session-08-Probability-Basics/session_8_probability_basics.ipynb) | ✅ Completed |
| **09** | **Normal Distribution** | Generating $N(50, 10^2)$ bell curve with PDF overlay plot, fitness step counts Mean $\approx$ Median $\approx$ Mode symmetry check, 200 gamer scores 68-95-99.7 empirical rule verification ($1\sigma \in [55, 85]$), Spotify song durations normal distribution modeling | [Session 09 Notebook](./Session-09-Normal-Distribution/session_9_normal_distribution.ipynb) | ✅ Completed |
| **10** | **Bayes Theorem (Basic)** | General `bayes_posterior` function, Swiggy premium restaurant discount inference ($P(\text{Premium} \mid \text{Discount}) = 30.77\%$), 20-email Naive Bayes spam keyword filter, Flipkart fake review fraud detection model & prompt | [Session 10 Notebook](./Session-10-Bayes-Theorem-Basic/session_10_bayes_theorem_basic.ipynb) | ✅ Completed |
| **11** | **Vectors & Matrices (Basic)** | 1D playlist duration vector operations, 3x3 Swiggy ratings matrix column slicing, 3x4 restaurant dishes order aggregation (`axis=0`), 5x2 Flipkart product sales matrix & revenue calculation function | [Session 11 Notebook](./Session-11-Vectors-Matrices-Basic/session_11_vectors_matrices_basic.ipynb) | ✅ Completed |
| **12** | **Matrix Multiplication & Linear Regression Math Intuition** | 2x2 matrix multiplication for Instagram engagement ($A \times B$), `linear_regression_predict(x, m, c)` function ($y = mx + c$), Zomato delivery time prediction ($y = 4x + 10$) with regression visualization, Flipkart price prediction slope & intercept intuition, and Spotify recommendation system matrix factorization intuition | [Session 12 Notebook](./Session-12-Matrix-Multiplication-Linear-Regression/session_12_matrix_multiplication_linear_regression.ipynb) | ✅ Completed |
